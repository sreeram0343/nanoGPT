# Tiny GPT

A small character-level GPT language model built from scratch using PyTorch, inspired by Andrej Karpathy's Tiny Shakespeare project. The project focuses on understanding the core concepts behind Transformer-based language models, from text tokenization to training and text generation.

## Current Model

- Parameters: ~1M ( 0.85 M )
- Character-level tokenization
- Text encoding and decoding
- Training and validation data preparation
- Batch generation and context windows
- Token and positional embeddings
- Self-attention and Transformer blocks
- Next-token prediction and text generation

## Future

The goal is to progressively scale the model beyond its current ~1M parameters and experiment with larger datasets, improved tokenization, and better training techniques.

Planned directions:

- Higher-parameter model architectures
- Larger and more diverse datasets
- BPE/subword tokenization
- Improved training and sampling techniques
- Model evaluation and checkpointing
- Instruction tuning and fine-tuning
- Building increasingly capable small-scale LLMs

## Goal

Build progressively larger language models from scratch while developing a practical understanding of how modern LLMs are designed, trained, and improved.
